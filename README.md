# 需求评分工具集

> AI 驱动的需求工程工具：从代码反推需求文档 + 从 PRD 计算贡献分。

## 包含的子 Skill

| 子 Skill | 功能 | 输入 | 输出 |
|----------|------|------|------|
| 需求文档反推 | 代码仓库 → 需求文档 | Git 仓库 | 按标准模版格式的 PRD |
| 需求贡献分评分 | 需求文档 → 贡献分 | PRD/TRD 文档 | 双版本（算前端/不算前端）评分 + 多人贡献分拆解 |

## 核心原则

- 规则固定、输入客观、过程可复现、结果可审计
- 每项计数附带原文依据，可逐项手动验算
- 开发者复核确认后进入分成池

## 安装

```bash
# 复制到项目
cp -r 需求评分 /your-project/.claude/skills/

# 或全局安装
cp -r 需求评分 ~/.claude/skills/
```
